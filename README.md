# Art Engine Lab

*A creative laboratory for understanding, reconstructing, and generating visual artwork through code, mathematics, and AI assistance.*

## Purpose

This is a **planned monorepo** of related but independently developed art-technology experiments. It begins with recreating existing raster art (such as PNG banners, logos, and seamless tiles) using structured, scalable techniques; over time, successful experiments may become modules in a unified art toolbox.

The emphasis is on **learning by reconstruction** and retaining **artist control** over mathematically precise systems.
