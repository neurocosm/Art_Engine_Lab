# Provisional Roadmap

**Not a committed schedule.** Work should begin with whichever simple reference image best teaches the next useful technique.

## Stage 0 — Preserve context (now)

- [x] Summarize project vision and ideas in Markdown.
- [x] Record confirmed directions separately from proposals.
- [x] Draft initial Codex guidance.
- [ ] Create/recreate the GitHub repository and add the starter documents.
- [ ] Choose a first owned/licensed reference image.

## Stage 1 — Small independent experiments

- [ ] Basic SVG reconstruction of a simple shape/logo/banner.
- [ ] Basic seamless tiling viewer with repeat preview.
- [ ] X/Y origin/phase controls with immediate preview updates.
- [ ] Validate simple repeat edge continuity; document limitations.

## Stage 2 — Tile Lab refinement

- [ ] Separate tile-cell alignment from motif movement.
- [ ] Support stagger/half-drop or brick repeats.
- [ ] Add seam inspection and reversible adjustment controls.
- [ ] Export validated SVG or PNG results as appropriate.

## Stage 3 — Raster understanding

- [ ] Palette and region analysis.
- [ ] Rebuild linework/geometry as editable vector layers.
- [ ] Compare output to reference at multiple scales.
- [ ] Explore AI-assisted interpretation with user review.

## Stage 4 — Optional convergence

- [ ] Evaluate a common layer/scene description.
- [ ] Integrate useful experimental components into a unified UI.
- [ ] Explore prompt-to-art and print-oriented workflows.

## Done means something observable

For each experiment, save the reference, source code, generated outputs, a short usage guide, known limitations, and at least one visual comparison. Do not mark a task complete solely because code runs.
